Демонстрация форм tpchel.ru
Запуск из папки demo: python -m http.server 8766 --bind 127.0.0.1
Открыть http://127.0.0.1:8766/
Напрямую через file:// формы не загружаются: используется AJAX.
Три формы, Calltouch исключён. Данные не передаются, не записываются в хранилище и очищаются при новом открытии формы. Файл резюме остаётся локальным, содержимое не читается.
Документы — явно обозначенные заглушки, тексты готовятся после утверждения форм.
Перед интеграцией нужны реальные адреса документов, идентификаторы CMS, состав заказа и маршрутизация специалистам/вакансиям. В демонстрации добавлены обязательные почта и сообщение для консультации, имя и почта для отклика; их окончательную обязательность согласовать при внедрении.
Серверная проверка согласия и фиксация версии согласия обязательны для будущей интеграции, демонстрация их не реализует.

Форма «Заказ» уточнена по скриншоту: две колонки, пример товара, количество, удаление и пустое состояние. «Добавить ещё товары» закрывает окно; реальный каталог пока не подключён. При новом открытии пример восстанавливается. Проверены мобильные ширины и блокировка отправки пустой корзины.
